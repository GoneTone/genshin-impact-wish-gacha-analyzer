# App icon 與 AppBar logo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把舊版 (master 分支) 的 app icon 帶回 flutter-rewrite — AppBar 標題前顯示 logo，Windows .exe 也用正式 icon 取代 Flutter 預設範例 icon。

**Architecture:** 新增單一 `assets/icons/app_icon.png` 給 Flutter UI 使用、覆寫 `windows/runner/resources/app_icon.ico` 給 Windows 編譯使用。`AppBar.title` 改為 `Row(Image.asset + SizedBox + Text)`，inline 不抽 widget（YAGNI）。

**Tech Stack:** Flutter 3.x、Material AppBar、Flutter assets 機制、Windows runner Resource Compiler (`Runner.rc` / `IDI_APP_ICON`)。

**Spec：** `docs/superpowers/specs/2026-05-10-app-icons-design.md`

### Task 1: 從 master 分支取得 icon 檔案

**Files:**
- Create: `assets/icons/app_icon.png` (來源 `master:build/icons/256x256.png`，256×256 PNG)
- Overwrite: `windows/runner/resources/app_icon.ico` (來源 `master:build/icons/icon.ico`，多解析度 .ico)

**注意：** 兩個都是 binary 檔。PowerShell 的 `>` 重導向會破壞 binary（轉 UTF-16 / 加 BOM），**必須用 Bash 工具**做 redirection；或用 `git show` 搭配 `Set-Content -AsByteStream`（PowerShell 7+）。本 plan 使用 Bash 工具。

- [ ] **Step 1: 建立 assets 目錄**

Run (Bash 工具):
```bash
mkdir -p assets/icons
ls -la assets/icons
```

Expected: 目錄建立成功，`ls` 顯示空目錄 (`. ..` 兩項)。

- [ ] **Step 2: 從 master 取出 app_icon.png**

Run (Bash 工具):
```bash
git show master:build/icons/256x256.png > assets/icons/app_icon.png
ls -la assets/icons/app_icon.png
file assets/icons/app_icon.png
```

Expected:
- `ls -la` 顯示檔案大小約 30,000–100,000 bytes（256×256 PNG 合理範圍）
- `file` 顯示 `PNG image data, 256 x 256, ...`（若 `file` 命令不存在可跳過此驗證）

- [ ] **Step 3: 覆寫 Windows app_icon.ico**

Run (Bash 工具):
```bash
git show master:build/icons/icon.ico > windows/runner/resources/app_icon.ico
ls -la windows/runner/resources/app_icon.ico
file windows/runner/resources/app_icon.ico
```

Expected:
- 檔案大小應該明顯改變（原本 Flutter 預設 .ico 約 33KB；新 .ico 通常 100KB+）
- `file` 顯示 `MS Windows icon resource - X icons, ...`

- [ ] **Step 4: Sanity check — 兩個檔案不是空的，也不是 Git LFS pointer**

Run (Bash 工具):
```bash
head -c 16 assets/icons/app_icon.png | xxd
head -c 16 windows/runner/resources/app_icon.ico | xxd
```

Expected:
- PNG: 開頭 `89 50 4e 47 0d 0a 1a 0a` (PNG magic bytes `\x89PNG\r\n\x1a\n`)
- ICO: 開頭 `00 00 01 00` (ICO file header)

若看到 `version https://git-lfs.github.com/...` 之類字串就是 LFS pointer，需要 `git lfs pull` 或改用 `git cat-file blob` + 二進位 redirection。

- [ ] **Step 5: Commit**

Run:
```bash
git add assets/icons/app_icon.png windows/runner/resources/app_icon.ico
git status
git commit -m "$(cat <<'EOF'
chore(icons): bring app icon assets from legacy master branch

- assets/icons/app_icon.png  : 256×256 PNG, 給 AppBar UI 使用
- windows/runner/resources/app_icon.ico : 覆寫 Flutter 預設範例 icon

兩者皆取自 master:build/icons/。Runner.rc 已透過 IDI_APP_ICON
引用 app_icon.ico，不需修改 .rc。
EOF
)"
```

Expected: commit 成功，`git status` 顯示 working tree clean。

### Task 3: 修改 AppBar 加上 logo

**Files:**
- Modify: `lib/pages/app_shell.dart` (第 60–76 行的 `appBar:` 區塊內的 `title:`)

- [ ] **Step 1: 編輯 app_shell.dart**

第 60–76 行原本長這樣：

```dart
return Scaffold(
  appBar: AppBar(
    title: Text('${l.appName} v$version'),
    actions: [
      const UidIndicator(),
      Padding(
        padding:
            const EdgeInsets.symmetric(horizontal: AppSpacing.m, vertical: AppSpacing.s),
        child: FilledButton.icon(
          icon: const Icon(Icons.refresh),
          label: Text(l.actionUpdate),
          onPressed: () async {
            await ref.read(wishRepositoryProvider.notifier).update();
          },
        ),
      ),
    ],
  ),
```

把 `title: Text('${l.appName} v$version'),` 這一行改為：

```dart
    title: Row(
      mainAxisSize: MainAxisSize.min,
      children: [
        Image.asset(
          'assets/icons/app_icon.png',
          width: 28,
          height: 28,
          filterQuality: FilterQuality.medium,
        ),
        const SizedBox(width: AppSpacing.s),
        Text('${l.appName} v$version'),
      ],
    ),
```

**重要：**
- `mainAxisSize: MainAxisSize.min` 不能省 — 否則 Row 會撐到滿版把右側 actions 推出畫面。
- `width/height: 28` 是 dp，AppBar 預設高度 56dp，上下各留 14dp padding。
- `filterQuality: FilterQuality.medium` 讓 256px → 28dp 縮圖更平滑。
- 不抽 `AppLogo` widget — 只有此處使用，YAGNI。

`actions:` 區塊不動。

- [ ] **Step 2: 跑 flutter analyze**

Run:
```bash
flutter analyze
```

Expected: `No issues found!` — 確認沒寫錯 import / 拼字 / type。

- [ ] **Step 3: 跑既有 test 確認無迴歸**

Run:
```bash
flutter test
```

Expected: 全部 test pass。本次改動不涉及任何被現有 test 涵蓋的 widget（`page_header_test.dart` / `pager_test.dart` 等），理應不會壞。如有失敗，回頭檢查 Step 1 是否誤動到 `title` 以外的程式碼。

- [ ] **Step 4: Commit**

Run:

### Task 4: 手動視覺驗證 (Windows)

**Files:** 無變更 — 純跑 app 確認效果。

此 task 不可自動化，需要實機跑 Flutter 並用人眼確認。如果在 CI / 無 GUI 環境執行 plan，**此 task 必須延後到本機執行**，但前面三個 task 的 commit 已可成立。

- [ ] **Step 1: Hot run 確認 UI**

Run:
```bash
flutter run -d windows
```

Expected (人眼確認):
- AppBar 左側顯示 logo（圓形/方形彩色 app icon）緊鄰「App 名稱 v0.x.x」文字。
- 右側 UidIndicator + 「更新」按鈕仍正常顯示。

操作驗證：
- 進入「設定」頁，切換 dark ↔ light theme — logo 在兩主題下都應清晰可辨。
- 切換語言（系統 / 繁中 / 簡中 / 英文）— 標題長度變化下不破版（極窄視窗 ellipsis 是既有行為，可忽略）。
- 切換到不同 banner page、Settings page — AppBar 是 `AppShell` 共用，logo 在所有頁面都應顯示。

如果 logo 不出現：
- 檢查 `flutter pub get` 是否在 Task 2 跑過
- 檢查 `assets/icons/app_icon.png` 是否存在且為合法 PNG (Task 1 Step 4)

- [ ] **Step 2: 結束 hot run，重新 build Windows exe**

按 `q` 結束 `flutter run`，然後：

```bash

```

Expected: `Built build\windows\x64\runner\Release\genshin_impact_wish_gacha_analyzer.exe` 訊息結尾。

**為什麼要 build：** Windows .ico 是透過 `Runner.rc` 編進 .exe 的，hot reload / hot restart 都不會觸發 C++ rebuild — 必須完整 `flutter build windows`（或刪 `build/windows/` 後再 `flutter run`）才會把新 icon 包進 exe。

1. 檔案總管中 `.exe` 檔案的圖示
